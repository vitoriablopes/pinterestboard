📌 Pin2PDF

Cole o link de um board do Pinterest, escolha as imagens e gere um PDF para imprimir.

1. Carregar imagens

O board precisa ser público. O Pinterest costuma liberar só as ~25 pins mais recentes por esse método. Se o link não funcionar, adicione imagens manualmente abaixo.
Proxy próprio (recomendado se boards e links de pin não funcionarem)
Os proxies públicos usados por padrão são instáveis e costumam ser bloqueados pelo Pinterest. Com um proxy seu (Cloudflare Worker gratuito, arquivo worker.js), board e links de pin passam a funcionar de forma confiável.

2. Configurar PDF / DOCX

No DOCX as imagens ficam em linha, como texto: o Word reorganiza as quebras de linha e o espaço entre imagens é aproximado.

3. Escolher imagens
